# Kimi Code Token 监控 Dashboard —— 第二轮 UI 还原与精细化改造 Agent 提示词

## 任务定位

这是对当前 Kimi Code Token 监控页面进行的**第二轮 UI 还原**。

前一轮已经完成了基础的 Dashboard 重构，但从当前实际页面截图来看，页面虽然已经接近目标方向，但仍然存在明显的：

- 页面整体尺寸偏小
- 内容过于压缩
- KPI 层级不够突出
- 面板间距和留白不足
- 图表高度不足
- 模型 / 会话区域的信息权重不平衡
- 历史区域过长但视觉表达过弱
- 实时事件区域过于拥挤
- Header 信息过于集中
- 页面没有充分还原“成熟开发者工具 Dashboard”的视觉层级

本轮任务不是重新发明一个设计，而是：

> **基于当前代码和当前截图，继续向高质量专业 Dashboard UI 还原。**

核心目标：

> **保留现在已经正确的功能和数据结构，把页面做得更接近一个真正成熟的 AI Coding Observability / Token Monitoring 产品。**
