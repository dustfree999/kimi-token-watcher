# Kimi Code Token 监控 —— 新版 UI 设计改造 Agent 提示词

> 目标：在**不破坏现有数据采集、统计口径、API、交互逻辑和文件结构**的前提下，对当前 Kimi Code Token 监控页面进行一次完整的 UI/UX 重构。
>
> 本提示词可以直接复制给负责前端页面改造的 Agent 使用。

---

## 一、任务目标

请直接修改当前项目中的前端页面，实现一套新的 **Kimi Code Token 监控 Dashboard UI**。

这次任务的核心不是新增复杂业务功能，而是：

1. 保留现有功能和数据；
2. 重新设计页面的信息层级；
3. 提升 Dashboard 的专业感、现代感和可读性；
4. 让页面更像成熟的开发者监控产品，而不是普通数据展示页面；
5. 保持深色数据监控风格；
6. 重点优化桌面端，同时保证平板和手机端基础可用；
7. 所有真实数据继续来自现有 `/api/usage`；
8. 不允许为了视觉效果把真实数据改成静态假数据。

